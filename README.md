Entry for the make.fun contest "The Best Meal You Ever Had": one sentence,
at most 200 characters, about the best meal ever eaten — nasi goreng from a
street cart at 2am, eaten standing up, wok smoke in the eyes, the egg still
runny on top.

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set). Stdlib only, no network, no dependencies.
